projects

Most of these are the same problem in different clothes: how do you build something that cannot quietly lie to you about what it found. Several are still private, so only some have source links.

Autonomous Science

Asilia

An offline-first autonomous research loop. State a goal in one sentence and it designs experiments under a hash-sealed contract, runs them, admits raw measurements through an auditable authority chain, updates its model, and stops at a preregistered budget. Provenance is enforced by the database rather than by good intentions: a direct write of measured state dies at a trigger, so simulated data cannot be laundered into a real result. Runs entirely local, including inference. Built at Contineon.

Python Rust React Tauri Local LLM
DEDUCE

A symbolic deduction harness where a learned component may only order the search. Exact verifiers decide truth, and what ships is a certificate someone else can re-check. It was aimed at five exact math and physics frontiers with preregistered kill criteria, and it failed all five. That is reported at length rather than worked around. The real contribution is the certificate layer: an auditor plus Lean 4 kernel-checked artifacts, in a loop where no human writes the proof.

Python Lean 4 SymPy
FIRST LIGHT

A search engine whose candidates must pass an exact, sealed admission predicate. It re-earned the complex numbers, quaternions and octonions from scratch, certified dimension 3 empty by exhausting 244,672,066 members, and refused dimension 16 four times out of four, exactly where Hurwitz put the wall in 1898. Arithmetic is exact int64 and never floating point, and every positive certificate is re-verified by an independent path that shares no code with the primary one.

Python NumPy Z3
LODESTONE

A foundation model that learns from rules instead of labels. A verifier supplies the prior that missing labels would have, so a small model on sparse data behaves as though it had far more. It was publicly refounded after an adversarial audit found the shipped engine had degenerated into per-problem stochastic search behind a grammar mask. The headline number was retracted and restated honestly: 15.6 of 45 against cvc5 at 41 of 45. The one measured win is robustness to label noise, and the repo says so instead of claiming more.

Python PyTorch Lean

OpenRocket Plus
Source

A fork of OpenRocket that extends the classical Barrowman calculator with physics-based supersonic and hypersonic models valid past Mach 10. It adds a shock-geometry pre-pass that marches the body nose to tail, oblique shock and Taylor-Maccoll cone flow, Prandtl-Meyer expansion, and base drag. Subsonic behavior is unchanged on purpose: below Mach 1 the new path is an inert passthrough with zero overhead. Twenty-two subsystems are externally benchmarked, each tied to a citable source and a measured error.

Java Aerodynamics Gradle
Cayley World Model

A domain-neutral architecture for trainable physical world models: a persistent belief over physical state, mechanism, instrument condition and competing explanations, with non-identifiability, contradiction and refusal represented explicitly rather than papered over. The Rust core has no third-party dependencies by design, with hand-written CUDA kernels and an f64 CPU path kept as the semantic oracle. Information geometry, sheaf gluing and Clifford carriers are all retained only as conditional mechanisms, never as defaults until they beat a simpler control.

Rust CUDA PyTorch
Borel

A locally runnable, verifiable poker engine aimed at the regimes nobody has solved: ultra-deep stacks, multiway pots, and imperfect-information edge cases. The Rust core has zero third-party dependencies, by design. It runs on a rule of no claim without a receipt, with committed receipts bound to a git commit and a source checksum, preregistration before every run, and a claims ledger with exactly three states. "Unexploitable" is banned vocabulary.

Rust Python CUDA
bazaar-quant

A trading system for an in-game commodity market. It collects the full order book around the clock, runs a multi-strategy signal engine over it, and serves a dashboard that says exactly which orders to place, all executed by hand so no automation ever touches the game client. Five dependencies, no pandas and no machine learning. When coverage is too thin to support an honest estimate, the model declines to quote rather than quoting a flattering one.

FlowQuake
Source

A neural point process for earthquake forecasting, pairing a selective state-space model with a rectified-flow head and benchmarking it against region-fitted ETAS across six regions. Every number in the writeup is read from a committed artifact, and the claim-to-artifact map deliberately includes the claims that failed to trace.

fMRI-Abstention
Source

Conformal selective risk control for fMRI brain decoding. The negative result is the contribution: the risk control collapses under cross-subject shift. Two scope limits are load-bearing, so they are stated at the top of the README rather than buried at the bottom.

Python PyTorch Neuroimaging
Deepkerr

Reduced-basis reliability in gravitational-wave simulation-based inference, testing a CNN against an SVD and MLP amortizer on effective spin. A first-principles audit turned up statistical, simulator and reproducibility defects, so the README states plainly that the current evidence supports a narrow engineering result and not an information-theoretic one.

Contineon
Source

The marketing site and customer dashboard for Contineon. React and Vite on the front, Supabase with row-level security and edge functions on the back, Stripe for billing, deployed to Cloudflare Pages. The browser only ever holds the anonymous key and every write goes through an edge function, which is covered by its own security test. Where there is no data yet, customers get an honest empty state instead of fake demo numbers.
